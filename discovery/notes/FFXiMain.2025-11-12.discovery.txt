map from. The verdicts were made from this build's own gate reports (below), and the one address
the macOS host needs to run was found directly:

------

3 suspect functions and 4 switches to review; FFXi.dll's with 1 suspect function. Each site was
read by disassembly and matched to a class the earlier builds record; one --reuse run each passed.
