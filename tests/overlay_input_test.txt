# The overlay's input capture (tests/overlay_input_test.sh): SDL events through the window's input
# hook, with tests/addons/inputtest's windows. Scancodes: 26 W, 43 Tab, 41 Escape. ImGui takes one
# change of a key a frame (its input trickling), so a few frames follow the keys before the mouse moves.
load inputtest
